# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in Pocket Remote, please report it privately through GitHub instead of publicly opening an issue.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Possible impact
- Any suggested solution

Please do not publicly disclose a vulnerability before it has been reviewed.

## Supported Versions

The latest version of Pocket Remote is the primary supported version.

Security improvements may be included in future releases.

Thank you for helping keep Pocket Remote safe.
