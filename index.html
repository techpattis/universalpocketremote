Features

📡

Learn IR Signals

Capture infrared signals from almost any remote control and save them permanently.

💾

Store Buttons

Store up to 20 custom buttons with easy navigation through the OLED interface.

📺

OLED Interface

Simple and intuitive graphical menu with battery information and saved buttons.

🔋

Rechargeable

Powered by a 3.7V Li-Po battery with safe charging using the MCP73831 controller.

🚀

ESP32 Powered

Fast, reliable and fully open-source firmware running on the ESP32 platform.

🌍

Open Source

Released under the MIT License so anyone can build, modify and improve the project.

Hardware

🖥️

ESPDuino-32

Main development board based on ESP32.

📟

SSD1306 OLED

128×64 monochrome display for menus and status information.

📡

IR Receiver

38kHz infrared receiver for learning remote signals.

📤

KY-005 IR LED

Transmit saved infrared commands to your devices.

🎮

Joystick

Navigate through menus quickly and comfortably.

🔌

MCP73831 Charger

Safe charging for the built-in Li-Po battery.

How It Works

①

Learn

Select New Button, enter a name and point an IR remote at the receiver.

②

Save

The signal is automatically stored in memory for future use.

③

Transmit

Choose the saved button and instantly send the infrared signal.

Supported Protocols

📺

Popular Brands

Supports NEC, Sony, Samsung, LG, Panasonic, JVC, RC5, RC6, Sharp, Denon and many more thanks to the IRremoteESP8266 library.

⚡

RAW Recording

Unknown infrared protocols can also be recorded and replayed using RAW timing data.

💡

Wide Compatibility

Works with TVs, air conditioners, LED strips, projectors, fans and many other IR-controlled devices.

Technical Specifications

💾

Memory

Maximum of 20 saved buttons with RAW infrared data up to 300 samples.

🔋

Battery

950mAh rechargeable Li-Po battery with battery percentage indicator.

🔌

Charging

Powered safely by the MCP73831 charging IC while remaining portable.

Compatibility

ESPDuino-32 & ESP32-WROOM

Pocket Remote was originally developed using the ESPDuino-32 development board. Since ESPDuino internally uses the ESP32-WROOM module, the exact same firmware also works perfectly on a standard ESP32-WROOM DevKit without changing a single line of code.

Open Source
