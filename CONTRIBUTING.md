# Contributing to Pocket Remote

Thanks for your interest in Pocket Remote!

## How to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Improving the code
- Testing the project
- Sharing ideas and feedback

## Before Opening an Issue

Please check existing issues first to avoid duplicates.

## Pull Requests

When submitting a pull request:

1. Explain what you changed.
2. Explain why you changed it.
3. Test your changes if possible.
4. Keep changes focused and easy to understand.

Every contribution is appreciated!
