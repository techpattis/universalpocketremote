# Code of Conduct

## Our Commitment

Pocket Remote is an open-source project and we want everyone to feel welcome.

## Expected Behavior

- Be respectful and kind.
- Give constructive feedback.
- Help other contributors when possible.
- Respect different experience levels and opinions.
- Keep discussions focused on the project.

## Unacceptable Behavior

Harassment, discrimination, threats, insults, personal attacks, spam, and deliberately disruptive behavior are not welcome.

## Reporting

If you experience unacceptable behavior, please contact the project maintainer through the GitHub repository.

Thank you for helping make Pocket Remote a friendly open-source project.
